# HydratorIO

### Links 

[Jetbrain Marketplace](https://plugins.jetbrains.com/plugin/25445-hydratorio)

### Description 

 A lightweight and simple plugin designed to help developers stay hydrated by reminding you to drink water at regular intervals.

- **Customizable Reminder Intervals**: Set reminder intervals to fit your coding schedule.
- **Non-Intrusive Notifications**: Get subtle reminders without disrupting your workflow.
- **Health and Focus Boost**: Stay energized and focused during long coding sessions by staying hydrated.

Perfect for developers spending extended hours in IntelliJ, providing a gentle reminder to prioritize well-being!
